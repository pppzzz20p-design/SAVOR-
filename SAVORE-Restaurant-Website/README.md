# SAVORÉ — International Restaurant Website

เว็บไซต์ร้านอาหารนานาชาติแบบ Responsive สร้างด้วย HTML, CSS และ JavaScript

## ฟีเจอร์
- หน้าแรก / Hero section
- เมนูอาหารพร้อมตัวกรองหมวดหมู่
- ระบบเพิ่มสินค้าและตะกร้า
- เพิ่ม/ลดจำนวนสินค้า
- ระบบ Checkout จำลอง
- บันทึกตะกร้าด้วย LocalStorage
- โปรโมชั่นและคัดลอกโค้ดส่วนลด
- ฟอร์มติดต่อ
- Responsive สำหรับมือถือ / Tablet / PC

## วิธีเปิด
เปิดไฟล์ `index.html` ใน Google Chrome ได้ทันที

## วิธีนำขึ้น GitHub Pages
1. สร้าง Repository ใหม่ใน GitHub เช่น `savore-restaurant`
2. อัปโหลด `index.html`, `style.css`, `script.js` และ `README.md`
3. ไปที่ **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/ (root)`
6. กด Save
7. GitHub จะสร้างลิงก์เว็บไซต์ให้ เช่น `https://ชื่อผู้ใช้.github.io/savore-restaurant/`

> หมายเหตุ: ระบบสั่งซื้อในเวอร์ชันนี้เป็น Demo ฝั่งหน้าเว็บ ยังไม่ได้เชื่อมฐานข้อมูล/ระบบชำระเงินจริง
